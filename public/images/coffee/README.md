# Screenshot upload slots

Upload original images here. Do not replace them with generated dashboards or spreadsheets.

Recommended filenames:
- sales-overview.png
- monthly-detail.png
- excel-original.png
- excel-orders.png
- excel-customers.png
- excel-products.png
- excel-formulas.png
- excel-pivots.png
- sql-kpi.png
- sql-joins.png
- sql-advanced.png
- sql-customers.png
- powerbi-model.png
- dax-measures.png
- readme.png
- business-questions.png
- documentation.png

In `src/data/coffee.ts`, add `image: 'images/coffee/filename.png'` to the corresponding `coffeeMedia` entry. Set the Coffee Sales project's `cover: 'images/coffee/sales-overview.png'` to replace its card placeholder. The report preview and galleries use the same media entries, preserve image aspect ratios, and open an enlargement dialog on click.
